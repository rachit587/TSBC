# The Story Begins Cafe

A premium, high-performance Next.js 16 restaurant website designed for The Story Begins Cafe in Rampurhat.

## Features
- **Next.js 16 App Router** with React 19
- **Tailwind CSS v4** & Framer Motion v12
- **Custom WebGL Shaders** for liquid metal buttons (`@paper-design/shaders`)
- **Luxury Green Design System** replacing default themes
- **Full SEO Optimization** with JSON-LD and Next.js Metadata
- **Mobile-First UX** with sticky bottom CTA bar

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment
This project is configured to deploy seamlessly on Vercel or Netlify. For Netlify, the `@netlify/plugin-nextjs` and `netlify.toml` are included.
